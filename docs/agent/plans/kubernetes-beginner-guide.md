- deploy/README.md를 단일 진입점으로 하고 공통 가이드는 서버 선택 checkout에 포함되는 shared에 둔다.

- 앱별 실행 원본은 기존 앱 README에 유지하며 중복 명령을 최소화한다.
- 설치 기준 미확정 구간은 조회 방법·필요 입력·완료 조건까지 작성한다. 검증되지 않은 OS별 설치 명령을 완성된 절차로 제시하지 않는다.
- API/DB/auth/env 계약과 import 변경은 없다.
