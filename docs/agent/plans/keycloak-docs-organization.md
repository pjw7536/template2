# ExecPlan: Keycloak 설명 문서 체계화

## 목표
- 처음 읽는 운영자가 서버 설치와 realm 이후 설정을 구분하고 필요한 단계만 실행한다.
- 단계별 실행을 기본 안내로 통일하고 입력·속성 계약을 별도 참고 문서로 정리한다.

## 현재 상태
- README에 설치, 수동 YAML, 통합 실행, mapper 계약이 혼재한다.
- 단계별 실행 파일은 구현됐지만 다른 문서 일부는 통합 실행을 기본으로 안내한다.

## 범위
- deploy/keycloak의 모든 Markdown 문서, 서버 설치·claim 참고 문서 추가.
- 기존 실행 코드·env 값·mapper 정책은 변경하지 않는다.

## 설계
- README: 시작점, 용어, 문서 지도, 상황별 다음 행동.
- SERVER_SETUP: 서버 준비·배포·확인과 수동 배포 참고.
- SETUP_FLOW: 0~5 독립 단계 실행의 원본 안내.
- CLAIMS: User Profile·수신 mapper·발급 mapper 계약.
- DISCOVERY_SETUP: 사내 입력 해석과 통합 실행 선택지.
- env/README, TLS, SDWT_SETUP, k8s/README: 목적·선행 조건·실행·확인 구분.
- 기존 README 6~8절 링크는 해당 상세 문서로 안내하는 진입점으로 보존한다.
