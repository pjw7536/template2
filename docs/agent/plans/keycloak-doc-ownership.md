# ExecPlan: Keycloak 운영 문서 소유 위치 정리

## 목표
- Keycloak 전용 운영 내용은 deploy/keycloak에 둔다.
- 공통 도구·인프라·여러 앱 조합 안내는 shared에 유지한다.

## 현재 상태
- shared/docs/operations/cp1.md에 공통 Git 관리와 Keycloak 수동 배포 절차가 혼재한다.
- keycloak-fresh-start.md는 과거 일회성 DB 초기화 기록이다.
- 최초 설치 문서와 Headlamp 변경이 작업트리에 있어 보존한다.

## 범위
- 문서 이동·분리·참조 링크만 수정한다. 코드·env·클러스터는 변경하지 않는다.

## 설계
- Keycloak 운영 문서는 operations, 과거 초기화 기록은 operations/archive로 모은다.
- shared CP1 문서는 공통 파일·Git 관리만 설명한다.
- 공통 앱 안내에서 Keycloak 전용 실행 절차를 반복하지 않고 소유 문서로 연결한다.

## 실행 단계
- [x] 문서 이동·분리
- [x] 참조 링크·상대 경로 갱신
- [x] 링크·앵커·Bash 문법 검사

## 검증
- 변경 문서의 상대 링크·앵커 및 Bash 코드 블록 검사, git diff --check.
- 운영 명령은 실행하지 않는다.

## 위험과 대응
- 과거 데이터 삭제 기록의 오용: 최초 설치 경로와 분리하고 기록임을 명시한다.
- 다른 앱 변경 손실: 문서 대상만 수정한다.

## 진행 기록
- 2026-09-25: 문서 소유 영역별 분리 범위를 확정했다.

- 검증 완료: 변경 문서 9개 링크·앵커 110개, Bash 블록 26개, diff 공백 검사 통과. 이전 shared 초기화 문서 경로의 잔여 참조 없음. 서버 명령·커밋·push는 실행하지 않았다.
