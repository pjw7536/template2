# ExecPlan: ChatWidget 대화방 사이드바 너비 조절

## 목표
- 사용자가 ChatWidget의 대화방 목록과 채팅 본문 사이 구분선을 드래그해 사이드바 너비를 조절할 수 있다.
- 키보드 사용자도 같은 구분선에서 너비를 조절할 수 있다.

## 현재 상태
- `ChatWidget.jsx`가 위젯 크기와 포인터 상호작용 상태를 소유한다.
- `ChatWidgetPanel.jsx`의 대화방 목록 사이드바는 `w-52` 고정 너비였다.
- `ChatWidget.test.jsx`는 패널을 모킹해 위젯 상위 상태와 이벤트 연결을 검증한다.

## 범위
- ChatWidget 사이드바 너비 상태, 포인터/키보드 조작, 가변 너비 표현을 수정한다.
- 전체 Assistant 페이지의 사이드바와 서버 API, DB, auth 계약은 수정하지 않는다.

## 설계
- 기본 너비는 기존 `w-52`와 같은 208px로 유지한다.
- 너비는 176–360px 범위에서 제한하며, 위젯 자체가 좁아지면 채팅 본문 공간을 위해 최대 너비를 낮춘다.
- 포커스 가능한 `separator`가 드래그와 방향키, Home/End 입력을 받는다.
- feature facade, migration, env, auth 영향은 없다.

## 실행 단계
- [x] 사이드바 너비 상태와 제한 계산을 ChatWidget에 추가한다.
- [x] ChatWidgetPanel에 가변 너비와 접근 가능한 조절 구분선을 적용한다.
- [x] 드래그 및 키보드 조작 회귀 테스트를 추가한다.
- [x] 관련 단위 테스트와 UI 일관성 감사를 실행한다.

## 검증
- `npm run test:run -- src/features/assistant/components/ChatWidget.test.jsx`
- `npm run agent:audit:ui`
- 기대 결과: ChatWidget 테스트가 모두 통과하고, 이번 변경으로 새 UI 일관성 위반 후보가 생기지 않는다.

## 위험과 대응
- 위험: 사이드바를 넓히면 좁은 위젯에서 채팅 본문이 지나치게 줄어들 수 있다.
- 대응: 현재 위젯 너비에 따라 사이드바 최대 너비를 동적으로 제한한다.
- 위험: 포인터 드래그 중 텍스트가 선택되거나 커서가 흔들릴 수 있다.
- 대응: 드래그 동안 전역 커서와 텍스트 선택을 잠그고 종료 시 원래 값으로 복원한다.
