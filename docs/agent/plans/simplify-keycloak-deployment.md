# ExecPlan: Keycloak 배포 파일 단순화

## 목표
- CP1 운영은 기존 스택·mapper YAML 두 개로 통일한다.

## 현재 상태
- 서버 리소스 원본 5개, 생성물 4개 및 중복 Python 실행 도구가 있다.

## 범위
- 서버 원본 통합, 생성 스크립트, 중복 도구 제거, 배포 문서.
- Portal 원본과 사내 OIDC 접속 설정 기능은 유지한다.

## 설계
- 서버 원본은 stack.yaml로 통합하고 Kustomize는 이미지 및 ConfigMap 생성에 사용한다.
- rendered에는 기존 이름의 서버·mapper YAML만 생성한다.
- Portal client는 Portal 원본에서 필요할 때 직접 생성한다.
- Python 도구·전용 테스트 제거. 사용자 데이터 및 운영 클러스터는 변경하지 않는다.
