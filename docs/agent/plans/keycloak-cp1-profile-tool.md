# ExecPlan: CP1 사용자 속성 관리 도구

## 목표
- 사용자가 제공한 Python 도구를 현재 Keycloak 계약에 맞춰 제공한다.

## 현재 상태
- 기존 Job은 프로필 교체, 16개 속성 mapper, EPID username mapper를 관리한다.
- 제공 코드는 과거 19개 속성을 병합하므로 현재 결정과 다르다.

## 범위
- CP1 도구, 프로필 JSON 전달, 문서 및 독립 테스트. 앱 코드는 변경하지 않는다.

## 설계
- 기존 프로필 JSON을 단일 정의로 재사용한다. CP1에 Python과 JSON을 함께 전달한다.
- dry-run, 백업, 동시 변경 검사, 결과 검증 및 인증 파일 정리를 유지한다.
- avatarid 수집 userid mapper와 grdName/origincomp mapper를 제거한다.
- Portal client는 변경하지 않는다.

## 실행 단계
- [x] 도구 및 문서 작성
- [x] 독립 테스트와 구문 검증

## 검증
- Python 표준 라이브러리 unittest로 계획/충돌/실행 흐름 검증
- 기존 환경 테스트와 문서 검사

## 위험과 대응
- 다중 관리 요청은 원자적이지 않으므로 적용 전 백업을 남기고 부분 실패를 명시한다.
- 기존 사용자 레코드는 일괄 수정하지 않는다.

## 진행 기록
- 2026-09-14: 사용자가 제공한 코드를 기반으로 현재 프로필 정의와 일치시키기로 했다.
- 독립 테스트 5개, 기존 환경 테스트 30개, Python 3.8 구문 검사, 문서 검사 및 diff 검증 통과.
- 실제 CP1 및 운영 Keycloak에서 실행하지 않았다. 관리 API는 메모리 대역으로 검증했다.

- 후속 결정: 사용자가 YAML 운영 방식으로 통일하기로 하여 이 도구와 전용 테스트는 제거했다. 현재 구조는 [배포 단순화 계획](simplify-keycloak-deployment.md)을 따른다.
