# ExecPlan: Keycloak 최초 설치 안내 통합

## 목표
- 최초 설치만 설명하며 Keycloak 자체 설정을 완료한 뒤 Portal·Headlamp를 연결한다.
- 명령·설정 계약의 중복을 제거한다.

## 현재 상태
- 04와 05 문서가 같은 실행 명령을 반복하고, Portal 연결이 SDWT 초기 설정보다 먼저 나온다.
- SDWT 도구는 client 없이 그룹·사용자를 준비할 수 있다.

## 범위
- deploy/keycloak 문서와 관련 Portal 안내 링크, 실행 계획.
- 실행 코드·파일 이름·환경변수·권한 계약은 변경하지 않는다.

## 설계
- 서버 설치 → Realm·IdP·프로필·수신 mapper → 선택 SDWT → Account Console 시험 로그인 → 앱 연결.
- 04에 자체 설정 실행, 07에 client 없는 SDWT 등록, 새 09에 앱 연결 진입점을 둔다.
- 02·03·05·06·08은 입력/TLS/Discovery/매핑/원본 참고이며 실행 절차를 복제하지 않는다.
- 이전 환경 전환·재설치·통합 실행 설명은 최초 설치 가이드에서 제거한다.

## 실행 단계
- [x] 문서 역할별 재구성
- [x] 앱 연결을 별도 단계로 이동하고 실제 도구 의존성 확인
- [x] 링크·앵커·Bash 문법·Make 명령 검증

## 검증
- 문서 링크와 앵커 검사, Bash 코드 블록 bash -n, Make dry-run, server-check.
- 운영 클러스터에는 적용하지 않는다.

## 위험과 대응
- 스크립트 번호와 설명 순서 혼동: 문서 단계명으로 안내하고 파일명은 호환성을 위해 유지한다.
- Portal 이전 로그인 확인: 기본 Account Console을 이용한다.
- SDWT 그룹이 클러스터 관리 권한으로 오인됨: Headlamp 전용 그룹/RBAC와 분리한다.
