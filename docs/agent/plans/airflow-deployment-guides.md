# ExecPlan: Airflow 단계별 배포 문서

## 목표
- Keycloak처럼 상황별 시작점과 단계별 실행·완료 기준을 제공한다.

## 현재 상태
- deploy/airflow/README.md 한 파일에 준비·설정·배포·운영이 모여 있다.
- make airflow-up은 신규 DAG를 일시정지하지만 직접 deploy의 기본값은 활성화다.

## 범위
- deploy/airflow의 Markdown 문서와 이 계획만 변경한다.
- 기존 사용자 변경과 실행 코드·실제 env·클러스터는 유지한다.

## 설계
- README를 문서 지도로 바꾸고 서버, env, artifact, 실행, 운영 안내로 나눈다.
- 기존 명령과 설정 계약을 설명하며 API/DB/auth/env 계약 변경은 없다.

## 실행 단계
- [x] 기존 문서·실행 코드·지침 확인
- [x] 단계별 안내 작성 및 기존 설명 이동
- [x] 링크·명령 문법·배포 정적 검사 확인

## 검증
- 문서 상대 링크 존재 여부와 Bash 코드 블록의 bash -n 검사
- make server-check APP=airflow PROFILE=prod
- git diff --check
- 클러스터 적용·비밀값 초기화·이미지 빌드는 수행하지 않는다.

## 위험과 대응
- 위험: 직접 deploy와 make 명령의 동작 차이를 같은 절차로 안내할 수 있다.
- 대응: 기본 경로는 make로 통일하고 직접 실행 시 --pause-new-dags를 명시한다.
- 위험: 도구·chart 부재로 정적 검사가 중단될 수 있다.
- 대응: 실행 결과와 부족한 준비물을 구분해 기록한다.
