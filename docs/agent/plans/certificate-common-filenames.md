# ExecPlan: 도메인별 인증서 파일명 통일

## 목표
- DNS별 폴더에서 fullchain.crt, private.key를 공통으로 사용한다.

## 현재 상태
- Keycloak과 Headlamp는 서로 다른 인증서·개인키 이름을 사용한다.
- 현재 작업공간에 실제 인증서·개인키 파일은 없다.

## 범위
- deploy의 배포 코드·테스트·인증서 추출/적용 문서와 참조.
- PFX/P7B 원본, CA 파일명과 Kubernetes Secret 이름은 유지한다.

## 설계
- 사이트 폴더가 도메인을 구분하므로 파일명에서 서비스 접두어를 제거한다.
- 기존 서버 파일은 덮어쓰지 않는 명시적 이름 변경 절차를 문서화한다.

## 실행 단계
- [x] 코드·문서·추출 명령 참조 변경
- [x] 테스트·문서 셸 문법·잔여 참조 검사

## 검증
- shared Python 테스트와 배포 경계 Node 테스트.
- 인증서 안내 bash 블록 문법 검사, git diff --check.

## 위험과 대응
- 서버의 기존 파일은 Git에 없으므로 별도로 이름을 변경해야 한다.
- 파일 이름 변경 자체는 TLS Secret을 변경하지 않는다.

## 진행 기록
- 2026-09-23: 작업 시작. 실제 서버 파일은 변경하지 않는다.
- Keycloak 배포 코드·테스트와 양쪽 사이트의 추출·검증·등록·OIDC 문서를 공통 파일명으로 변경했다. CERT_PREFIX 변수는 제거했다.
- 이전 이름은 서버 파일 이관 명령에만 남겼다. 현재 작업공간에는 실제 인증서 파일이 없어 이름 변경 대상이 없었다.
- shared Python 38개 테스트 통과. 문서의 이름 변경 명령을 임시 파일로 실행해 내용 보존·충돌 시 중단·재실행을 검증했다. bash 문법과 git diff --check 통과.
