# ExecPlan: deploy 전반 점검

## 목표
- 설정·문서·배포 코드·검사·운영 복구의 부족한 부분을 점검하고 확인된 오류를 수정한다.

## 현재 상태
- 이전 env 분리 및 인증서 문서 변경은 미커밋 상태로 보존한다.
- 운영 클러스터 접근 없이 원본·렌더·회귀 테스트와 실제 env 검사를 수행할 수 있다.

## 범위
- deploy 전체 원본과 문서, 관련 Makefile 및 검사 도구 계약.
- 실제 클러스터 변경, 미확정 운영값 추측, 비밀값 재생성은 하지 않는다.

## 설계
- 코드의 명확한 사전검사 누락과 문서의 새 서버 절차·비밀값 위치 오류를 수정한다.
- 정적 검사와 실제 서버 준비 상태를 분리한 점검 결과를 deploy에 남긴다.

## 실행 단계
- [x] 앱별 배포 진입점·가이드·env 로더·검사 계약 조사
- [x] 확인된 코드·문서 오류 수정
- [x] 전체 정적 검사·관련 테스트·실제 env 및 문서 링크 확인
- [x] 미해결 운영 입력·서버 검증 항목 보고

## 검증
- 관련 Python·Node 회귀 테스트와 make server-check APP=all PROFILE=prod.
- 실제 env 검사는 실패 원인을 비밀값 없이 기록한다.
- 문서 로컬 링크, 셸 문법, git diff --check.

## 위험과 대응
- 정적 검사 통과를 운영 배포 성공으로 표현하지 않는다.
- 기존 Secret과 DB는 변경하지 않고 별도 운영 입력을 그대로 보존한다.

## 진행 기록
- 2026-09-23: 가이드와 코드 교차 점검 시작. Headlamp 최초 설치 전제, 비밀값 분리 후 백업 안내, Keycloak worker 스케줄 가능 여부 검사 누락을 확인했다.
- Keycloak cordon·차단 taint를 변경 전에 거부하도록 수정했다. Airflow 클러스터 입력 검사를 라우팅 변경 전으로 이동하고 기존 DB PVC의 비밀번호 Secret 유실 시 복원을 요구한다.
- Headlamp 최초 설치, Portal 비밀값 위치, Airflow 비밀값 백업 안내를 수정했다. deploy/READINESS.md에 앱별 현황·선행조건·검사 수준·적용 순서·복구 한계를 기록했다.
- Node 배포 검사 58개 통과. 전체 앱 6개 정적·렌더 검사, 문서 상대 링크 누락 0건, 셸 문법 및 git diff --check 통과.
- 실제 env 검사: Keycloak·Headlamp 통과. Airflow·Monitoring은 NODE_NAME 임시값, Portal API/Web/MinIO는 필수 DB·비밀값·공개 URL 미입력으로 실패한다. 값을 추측하지 않고 기록했다.
- 실제 인증서 파일 0개, 접근 가능한 context는 kind-tailwind-local뿐이다. 운영 TLS·이미지 pull·로그인·복원은 미검증이다. 클러스터 변경·커밋·push는 수행하지 않았다.
