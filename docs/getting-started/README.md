# 개발 시작 안내

[문서 홈](../README.md) · [다음: 개념 이해하기](../concepts/README.md)

개발 PC에서 Portal을 처음 실행하고 로그인하는 데 필요한 안내입니다.
전체 로컬 환경은 한 PC의 Docker에서 실행되며, 사내 서비스는 mock으로 대체합니다.
처음 도구·이미지·패키지를 받을 때는 인터넷 연결이 필요합니다.

## 처음 참여했다면

1. **[첫 셋업 가이드](01-setup.md)**에서 Linux·WSL2 도구와 배포 묶음을 준비합니다.
2. 같은 문서의 기동·로그인·검사 순서를 따라갑니다.
3. 작업을 마치면 종료와 데이터 보존 방법을 확인합니다.

브라우저 로그인과 준비 상태·통합 검사가 성공하면 첫 셋업을 마친 것입니다.
처음부터 서버용 env를 로컬로 복사하거나 DB를 초기화할 필요는 없습니다.

| 소스 변경 반영 | [이미지 갱신과 화면 개발](02-usage.md#소스-수정-반영) |

## 다른 실행 환경

Portal을 제외한 서비스만 필요하면 [플랫폼 로컬 실행](../../local/01-PLATFORM.md)을 따릅니다.
서버 설치는 [서버 배포 안내](../../deploy/README.md)에서 시작합니다.
개발 PC의 kind 실행과 실제 서버의 Kubernetes 배포는 준비 조건과 접속 주소가 다릅니다.
