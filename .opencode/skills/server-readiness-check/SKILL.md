# server-readiness-check

절차의 원본은 [배포 가이드의 설치 준비 점검](../../../deploy/README.md#설치-준비-점검)과 각 앱 가이드(`deploy/<app>/README.md`)의 `한눈에 보기`·`사람이 하는 일`이다.

## 진행 방법
1. 대상 앱을 정한다. 지정이 없으면 배포 가이드의 설치 순서대로 모든 앱이다.
2. 앱마다 설치 준비 점검의 1~4번을 실행한다. [조회]·[검사]만 실행하고 `사람이 하는 일` 표의 일 자체는 하지 않는다.
3. 결과를 원본 절의 표 형식으로 앱별로 정리하고, 마지막에 "지금 배포할 수 있는 앱"과 "사람 작업이 끝나야 하는 앱"을 나눈다.
4. 남은 서버 작업을 `deploy/shared/docs/infrastructure/pending.md`에 반영한다.

## 지킬 것
- 명령으로 확인하지 않은 항목을 `완료`로 쓰지 않는다. `사용자 보고`로 적힌 행은 `확인 필요`다.
- 사람에게 요청할 일은 가이드의 문구와 방법 링크를 그대로 옮긴다. 새 절차를 만들지 않는다.
- 준비가 끝난 앱이 있어도 이 스킬에서는 배포하지 않는다. 사용자가 배포까지 요청했으면 `server-deploy-routine`으로 이어서 진행한다.

## 보고 형식
- 앱별 표: 항목 | 상태(완료/미완료/확인 필요) | 근거 | 할 사람과 할 일
- 지금 배포할 수 있는 앱, 사람 작업이 끝나야 하는 앱과 막고 있는 항목
- 수정한 운영 기록 파일
