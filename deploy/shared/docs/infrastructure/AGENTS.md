# 사내 인프라 정보 관리 지침

분류표·기록 규칙·확인 상태·입력 양식은 [README.md](README.md)가 원본입니다. 이 파일은 에이전트 전용 순서와 검증만 정합니다.

## 읽기와 갱신 순서

1. 매 작업 시작 시 README.md를 읽고 작업 주제의 원본 문서만 추가로 확인합니다.
2. 관련 값·확인 상태·설정 원본·남은 확인을 작업 전제로 사용합니다. 실제 적용 전에는 필요한 최신 상태를 조회하거나 사용자에게 확인합니다.
3. 새 운영 정보를 받으면 README.md 기록 규칙에 따라 해당 원본의 현재 값을 갱신합니다. 기록 요청을 서버 적용 요청으로 확대하지 않습니다.
4. 저장소 선언을 바꿔 서버 재적용이 필요해지거나 서버 적용이 확인되면 [pending.md](pending.md)의 행을 추가·삭제합니다.
5. 실행 입력을 수정하는 작업이면 소유 앱의 manifest·env·Helm values와 설치 절차, README.md 분류표의 대조 정보를 함께 확인합니다.

## 검증과 보고

- 문서만 바꾸면 변경 파일의 링크·앵커와 `git diff --check`를 확인하고 `make audit-docs`를 실행합니다.
- 문서 이동·공통 경로 변경은 `node --test apps/tooling/tests/server-checkout.test.cjs`도 실행합니다. 기존 주소·서버/IP 대응·VIP backend 대응·전체 미러 목록의 보존을 원본과 대조합니다.
- 변경 경로·갱신한 정보·검증 결과·실제 서버 조회 여부·남은 확인을 보고합니다. 사용자 요청 없이 commit·push하지 않습니다.
